# Crypto Analysis Dashboard (Excel + Web Scraping)

## Overview
This project demonstrates an end-to-end data analytics workflow by collecting live cryptocurrency data through Python web scraping and transforming it into an interactive Excel dashboard.

## Workflow
1. Collected cryptocurrency data using Python (Requests & BeautifulSoup).
2. Cleaned and transformed the dataset.
3. Imported the data into Microsoft Excel.
4. Built Pivot Tables and Pivot Charts.
5. Designed an interactive dashboard using KPI Cards and Slicers.

## Dashboard Features
- Interactive filtering with Slicers
- Market Capitalization Analysis
- Top 10 Coins by Price
- Market Capital Share Distribution
- 1-Hour Price Change Analysis
- Price vs Dollar Volume per Supply
- KPI Cards for key metrics
